# Landing Page - Consultório Odontológico 🦷

> 🌐 **Acesse o projeto rodando aqui:** [https://github.io](https://jvco30.github.io/Consult-rio-Odontol-gico/)

Este é um projeto prático de landing page institucional para o nicho de saúde, desenvolvido para fins de estudo e hospedado diretamente no GitHub Pages.

### 🤖 Experimento de Desenvolvimento com Inteligência Artificial
O objetivo principal deste projeto foi testar a eficiência do modelo **Claude (Anthropic)** como um copiloto no desenvolvimento de software. A maior parte da estrutura visual foi gerada pela IA, enquanto a minha atuação se concentrou na gestão, curadoria e refinamento do projeto.

### ⚙️ O que eu pratiquei e aprendi nesse processo:
- **Construção de Instruções:** Aprendi a dar comandos mais claros e com restrições para evitar que a IA gerasse layouts quebrados.
- **Validação de Código e Correções:** Analisei o HTML e o CSS gerados pelo Claude, corrigindo manualmente as falhas de responsividade e ajustando a lógica dos formulários.
- **Resolução de Problemas (Debugging):** Quando a IA cometia erros ou "alucinava" no código, precisei analisar o erro técnico e enviar novos prompts corretivos de forma incremental.
- **Foco em Eficiência:** Busquei usar comandos diretos para entender como otimizar o tempo de desenvolvimento e o uso de recursos.

### 🛠️ Tecnologias Utilizadas
- HTML5 / CSS3 / JavaScript
- Claude LLM (Ferramenta de assistência técnica)
